# Scripts do core

## Orquestração local

| Script | Papel |
|--------|--------|
| [`../setup.sh`](../setup.sh) | Bancos + migração de dados + populate GeoServer (uma vez / sob demanda) |
| [`../start.sh`](../start.sh) | Sobe GeoServer + backend + frontend (dia a dia; **não** migra) |
| [`../config.sh`](../config.sh) | Adopter configuration wizard and apply command |
| [`common.sh`](common.sh) | Helpers compartilhados (source pelos dois scripts) |

```bash
./setup.sh          # prepara dados (volumes Docker); pergunta real vs demo
./start.sh          # sobe a aplicação
./setup.sh --quickstart       # seed de demonstração (sem JDBC; SRID 4674)
./setup.sh --skip-migration   # DBs + GeoServer layers only, no ETL or seed
```

`config.sh` is the recommended entry point for a real installation. It fills
`config/adopter/adopter-config.yaml`, which can also be edited in advanced mode
and applied with `./config.sh --apply`. The
`installation-config.json`, `mapLayersConfig.json`, and
`Job-Data-Migration/application/application.yaml` files are generated by
`config.sh`; `setup.sh` and `start.sh` do not create active files from
`.example`. Do not edit the generated contract keys directly.

The wizard asks for the setup mode before requesting migration fields. Choose
Quickstart to leave the wizard immediately and run `./setup.sh --quickstart`
followed by `./start.sh`.

No quickstart, `start.sh` não exige `adopter-config.yaml` e usa SRID 4674
temporariamente, sem alterar os valores persistidos no `.env`.

Demo: [docs/quickstart.md](../docs/quickstart.md). Seed SQL: [`config/db/seed/quickstart/`](../config/db/seed/quickstart/).

## Stack status

`./setup.sh --status` (or setup choice 3) and the end of `./start.sh` show each Compose
service as `STOPPED`, `RUNNING`, `HEALTHY`, `UNHEALTHY`, or `STARTING` from Docker state
and healthchecks. HTTP endpoints are listed but not probed.

## GeoServer

- Compose: `dsp-geoserver-exhibition`
- Docs: [docs/geoserver-exhibition.md](../docs/geoserver-exhibition.md)
- Populate: `./setup.sh` (publica layers via `/opt/populate_geoserver.sh`)

```bash
docker compose up -d --build dsp-geoserver-exhibition
docker compose exec dsp-geoserver-exhibition /opt/populate_geoserver.sh
```

Default WMS: http://localhost:22668/geoserver/dsp/wms
